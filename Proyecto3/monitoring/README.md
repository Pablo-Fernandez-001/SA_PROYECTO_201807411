# Observability

This folder is reserved for the phase 3 observability stack.

## Expected content
- ELK stack manifests or Helm values
- Prometheus scrape configs and alerts
- Grafana dashboards/exported JSON
- Node exporter or app metrics manifests

## Suggested structure
- `elk/`
- `prometheus/`
- `grafana/`
- `alerts/`

## Phase 3 goal
Centralize logs, expose metrics, and provide dashboards/alerts for the DeliverEats services.
